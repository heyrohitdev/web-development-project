# ✅ Daily Task Manager

A simple and interactive **Daily Task Manager** built using HTML, CSS, and JavaScript. This project helps users organize daily activities, track task progress, and manage their tasks through a clean and responsive interface.

## 🚀 Live Demo

🔗 **[View Live Demo](https://heyrohitdev.github.io/web-development-project/15-Daily-Task-Manager/)**

## ✨ Features

- ➕ **Add Tasks** — Create new tasks with a title, description, category, priority, and due date.
- 📝 **Task Management** — Add and delete tasks easily.
- ✅ **Task Completion** — Mark tasks as completed.
- 📊 **Progress Tracking** — View total, active, and completed tasks along with completion progress.
- 🔍 **Search Tasks** — Find tasks by their titles.
- 🗂️ **Task Filters** — Filter tasks by All, Active, and Completed.
- 📱 **Responsive Design** — Use the interface on different screen sizes.
- 🎨 **Interactive UI** — Enjoy styled buttons, task cards, and visual feedback.
